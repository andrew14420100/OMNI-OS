# OMNI OS

Sistema operativo per PC x86-64 basato su Fedora Kinoite (KDE Plasma, aggiornamenti
atomici), ampliato progressivamente con applicazioni, automazioni e AI locale.

**Stato:** fase M0 — sola documentazione tecnica. Nessun componente è
implementato o verificato. "OMNI OS" è un nome di lavoro, soggetto a verifica
del marchio prima di qualsiasi distribuzione pubblica.

Documentazione: [`docs/`](docs/README.md) — riferimento principale:
[specifiche funzionali v1.0](docs/00-specifiche/specifiche-funzionali-v1.0.md).
